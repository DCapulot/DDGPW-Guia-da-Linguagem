DDGPW

Uma linguagem de programação em português: declaração com tipo, palavras-chave em português e funções prontas para texto, vetores e matemática. Este guia cobre os 7 módulos.

texto usuario = "Admin"
inteiro pontos = 0
imprimir(usuario, " tem ", pontos, " pontos.")

1. Tipos de variáveis e constantes

A DDGPW é fortemente tipada na declaração: você diz o tipo de cada dado ao criá-lo.

1.1 Tipos suportados

TipoDescriçãoExemplos
inteiroNúmeros inteiros, positivos ou negativos42, -10
decimalNúmeros com fração (ponto flutuante)3.14, 0.5
textoCadeias de caracteres entre aspas duplas"Olá", "123"
booleanoValores lógicosverdade, falso
nuloAusência intencional de valornulo

1.2 Variáveis mutáveis

Sintaxe: tipo nome = valor. O valor pode mudar ao longo do programa.

inteiro contador = 0
decimal preco = 19.99
texto usuario = "Admin"

contador = contador + 1
usuario = "Editor"
imprimir(usuario, " tem ", contador, " pontos.")

1.3 Constantes

Com constante, o valor não pode ser alterado. Use para configurações e valores fixos.

constante decimal PI = 3.1415
constante texto NOME_SISTEMA = "DDGPW-v3"
// ERRO: PI = 3.14 (o sistema impede a mudança)

1.4 Verificação de tipos em tempo de execução

inteiro x = 10
imprimir(tipo_de(x))     // "inteiro"
imprimir(eh_inteiro(x))  // verdade
imprimir(eh_texto(x))    // falso

2. Vetores: criar e preencher

Vetores guardam várias posições de dados. O índice começa em 0. O tipo escrito na declaração é o tipo dos elementos.

2.1 Criar

Criação com tamanho fixo: criar_vetor(tamanho, valor_inicial) reserva o espaço na memória.

inteiro lista = criar_vetor(5, 0)   // 5 posições, todas com 0

Criação literal: com colchetes, vazio ou já com valores.

texto nomes = []
inteiro lista = [10, 20]

2.2 Preencher

Por índice, quando você sabe a posição (use com criar_vetor):

lista[0] = 100
lista[1] = 200
lista[2] = 300

Dinâmico, com empurrar, que coloca o valor na próxima vaga (use com vetor vazio):

empurrar(nomes, "Carlos")
empurrar(nomes, "Mariana")
empurrar(nomes, "José")

2.3 Preencher com laço PARA

Em vez de escrever posição por posição, use o contador i do laço.

inteiro numeros = criar_vetor(10, 0)
para i de 0 ate 9 passo 1 {
  numeros[i] = i * 10      // 0, 10, 20, 30...
}
imprimir(numeros)

Com entrada do usuário, usando capturar:

inteiro idades = criar_vetor(3, 0)
para i de 0 ate 2 passo 1 {
  idades[i] = capturar("Digite a idade da pessoa " + i + ":")
}
imprimir("Lista de idades cadastrada:", idades)

Com empurrar dentro do laço, partindo de um vetor vazio:

texto nomes = []
para i de 1 ate 3 passo 1 {
  texto n = capturar("Nome do aluno:")
  empurrar(nomes, n)
}
imprimir("Total de alunos:", tamanho_vetor(nomes))

3. Controle de fluxo

3.1 SE / SENÃO

inteiro idade = 17
se (idade >= 18) {
  imprimir("Acesso Liberado")
} senão {
  imprimir("Acesso Negado")
}

3.2 PARA (laço contado)

Estrutura: para [var] de [início] ate [fim] passo [incremento]. O fim é incluído. Ideal para percorrer vetores.

para i de 1 ate 5 passo 1 {
  imprimir("Volta número: ", i)
}

3.3 REPETIR (laço condicional)

Executa enquanto a condição for verdadeira.

inteiro energia = 3
repetir (energia > 0) {
  imprimir("Trabalhando... Energia restante: ", energia)
  energia = energia - 1
}

3.4 ESCOLHA (seleção múltipla)

Alternativa mais limpa a vários se seguidos. Cada caso termina com parar, e padrao trata o resto.

texto sinal = "amarelo"
escolha (sinal) {
  caso "verde": imprimir("Siga") parar
  caso "amarelo": imprimir("Atenção") parar
  caso "vermelho": imprimir("Pare") parar
  padrao: imprimir("Sinal estragado")
}

4. Operadores

4.1 Matemáticos

SímboloOperaçãoExemplo
+ -Soma e subtração10 + 5 → 15
* /Multiplicação e divisão20 / 4 → 5
%Resto da divisão10 % 3 → 1
++ --Incremento e decrementox++ (x vira 11)

4.2 Comparação

Sempre retornam verdade ou falso.

imprimir(10 == 10)  // verdade (igual)
imprimir(5 != 3)    // verdade (diferente)
imprimir(8 > 12)    // falso   (maior que)
imprimir(4 <= 4)    // verdade (menor ou igual)

4.3 Lógicos

e: verdade só se os dois lados forem verdade. ou: verdade se pelo menos um for. não: inverte o valor.

se (idade >= 18 e tem_cnh == verdade) { imprimir("Pode dirigir") }

booleano luz_acesa = falso
imprimir(não luz_acesa)   // verdade

4.4 Bits (baixo nível)

Manipulam o número em binário.

SímboloNomeExemplo
&E (AND)5 & 1
|OU (OR)5 | 1
~NÃO (NOT)~5
<< >>Deslocamento2 << 1 → 4

5. Funções de texto

5.1 Transformação

texto frase = "Linguagem DDGPW"
imprimir(maiusculo(frase))       // "LINGUAGEM DDGPW"
imprimir(minusculo(frase))       // "linguagem ddgpw"
imprimir(inverter_texto(frase))  // "WPGDD megaugnil"

5.2 Análise e busca

FunçãoO que fazExemplo
tamanho(t)Conta caracterestamanho("Oi") → 2
contem(t, b)Verifica se existecontem("Ola", "a") → verdade
indice_de(t, b)Posição da letraindice_de("abc", "b") → 1
comeca_com(t, p)Começa com...comeca_com("Abc", "A") → verdade

5.3 Recorte e limpeza

texto raw = "  espaços extras  "
imprimir(aparar(raw))        // "espaços extras"

texto link = "www.google.com"
imprimir(fatiar(link, 4, 10)) // "google"

5.4 Substituição e repetição

texto original = "banana"
imprimir(substituir(original, "a", "o"))  // "bonono"
imprimir(repetir_texto("A", 3))           // "AAA"

5.5 Texto para vetor

texto csv = "maçã,uva,pera"
inteiro lista = dividir_texto(csv, ",")
imprimir(lista[0])   // "maçã"

6. Funções de vetor

6.1 Adição e remoção

inteiro lista = [10, 20]
empurrar(lista, 30)         // [10, 20, 30]
inserir_inicio(lista, 5)    // [5, 10, 20, 30]
inteiro ultimo = remover_ultimo(lista)     // remove 30
inteiro primeiro = remover_primeiro(lista) // remove 5

6.2 Organização

FunçãoO que fazResultado
inverter(v)Inverte a ordem[1,2] → [2,1]
ordenar(v)Ordem crescente[3,1,2] → [1,2,3]
juntar(v, sep)Vira texto com separador"1-2-3"

6.3 Informações e buscas

inteiro v = [10, 50, 30]
imprimir(tamanho_vetor(v))   // 3
imprimir(indice_de(v, 50))   // 1
imprimir(contem(v, 100))     // falso

Note que indice_de e contem funcionam tanto em texto quanto em vetor.

6.4 Vetores padronizados

texto mapa = criar_vetor(100, "vazio")   // 100 posições com "vazio"

7. Funções matemáticas

7.1 Potência e raiz

imprimir(potencia(2, 3))     // 8
imprimir(raiz(25))           // 5
imprimir(raiz_cubica(27))    // 3

7.2 Arredondamento e absoluto

FunçãoO que fazExemplo

teto(n)Para cima4.1 → 5

7.3 Números aleatórios

decimal n = aleatorio()            // entre 0 e 1
inteiro dado = aleatorio_entre(1, 6)
imprimir("Você tirou: ", dado)

7.4 Trigonometria e constantes

imprimir(pi())          // 3.14159265...
imprimir(seno(90))
imprimir(cosseno(0))
imprimir(tangente(45))

Os ângulos de seno, cosseno e tangente são em radianos.

7.5 Máximos e mínimos

imprimir(maximo(10, 50, 2, 80))   // 80
imprimir(minimo(10, 50, 2, 80))   // 2

Exemplo completo

Um programa que junta constante, vetor, laço, condição e funções dos módulos acima: sorteia cinco dados e avisa se saiu algum 6.

constante inteiro QUANTIDADE = 5
inteiro sorteios = []

para i de 1 ate QUANTIDADE passo 1 {
  empurrar(sorteios, aleatorio_entre(1, 6))
}

imprimir("Dados: ", juntar(sorteios, "-"))

se (contem(sorteios, 6)) {
  imprimir("Saiu um 6!")
} senão {
  imprimir("Nenhum 6 desta vez.")
}
