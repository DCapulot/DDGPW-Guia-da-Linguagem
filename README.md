# 📘 DDGPW · Guia da Linguagem

Site de documentação da **DDGPW**, uma linguagem de programação em português criada por mim. O guia explica a linguagem do básico ao avançado, com exemplos de código em cada módulo.

[![Abrir o guia](https://img.shields.io/badge/Abrir_o_Guia-Aprender_DDGPW-2ea44f?style=for-the-badge)](https://dcapulot.github.io/DDGPW-Guia-da-Linguagem/)

🔗 **Site:** https://dcapulot.github.io/DDGPW-Guia-da-Linguagem/

## 🎯 Para quem é

Para quem quer aprender a programar na DDGPW, seja começando do zero ou já procurando os recursos mais avançados da linguagem. Tudo está escrito em português.

## 📚 O que você encontra

- Guia organizado em **7 módulos**, que vão do básico ao avançado
- **Exemplos de código** em cada módulo
- Navegação direta pelo navegador, sem instalar nada

## 🧪 Compilador

Para executar seus programas em DDGPW, use o compilador online. Ele roda direto no navegador, sem instalar nada.

[![Abrir o Compilador](https://img.shields.io/badge/Abrir_o_Compilador-DDGPW-1f6feb?style=for-the-badge)](https://dcapulot.github.io/DDGPW/)
[![Ver o Projeto](https://img.shields.io/badge/Ver_o_Projeto-GitHub-24292f?style=for-the-badge&logo=github)](https://github.com/DCapulot/DDGPW)

## 🚀 Como usar

1. Acesse o [site do guia](https://dcapulot.github.io/DDGPW-Guia-da-Linguagem/).
2. Comece pelo primeiro módulo e siga a ordem. Cada módulo se apoia no anterior.
3. Teste os exemplos de código no [compilador](https://dcapulot.github.io/DDGPW/) enquanto lê.

## 💻 Rodando localmente

O site é um único arquivo HTML, então não precisa de instalação nem de servidor:

```bash
git clone https://github.com/DCapulot/DDGPW-Guia-da-Linguagem.git
cd DDGPW-Guia-da-Linguagem
```

Depois, abra o arquivo `index.html` no navegador.
